# WATHIQ | وثيق — Ethereum File Timestamping MVP

مشروع عربي مفتوح المصدر لتسجيل **بصمة SHA-256** لملف في عقد ذكي فوق Ethereum. الحساب يجري محلياً في المتصفح؛ **الملف لا يُرفع إلى الشبكة**.

## شنو كيوفر؟
- حساب بصمة الملفات حتى 20 MB من الهاتف.
- تسجيل البصمة والوقت وعنوان المحفظة بواسطة `contracts/WathiqProof.sol`.
- البحث عن تسجيل سابق بنفس بصمة الملف وعنوان المحفظة عبر `recordedAt`.
- الواجهة `index.html`، ودوال التشفير والترميز `utils.js`، والاختبارات `tests/utils.test.cjs`.

## حدود الخدمة
هاد التسجيل **ماشي دليل ملكية قانوني**، وما يثبتش شكون أنشأ الملف أو واش المحتوى صحيح. أي شخص عنده نفس الملف يقدر يحسب البصمة. تسجيل المعاملة على شبكة عامة قد يكشف معلومات ارتباط الملف بمحفظة المستخدم. ما تشاركش المفاتيح السرية.

## تجربة الواجهة
من بعد تفعيل GitHub Pages على branch `main` من `/(root)`، الموقع كيتفتح عبر HTTPS، ويمكن حساب البصمات بلا ربط محفظة.

## تجربة العقد أولاً (Sepolia فقط)
1. نفتح `contracts/WathiqProof.sol` داخل https://remix.ethereum.org ونختارو Solidity ^0.8.24.
2. نجمع العقد ونختبرو على بيئة EVM تجريبية.
3. النشر على **Sepolia** يتطلب من مالك محفظة تجريبية توقيع معاملة باستخدام test ETH فقط.
4. نتحقق من العنوان والمعاملة على https://sepolia.etherscan.io.
5. ندخلو عنوان العقد المنشور في الواجهة، ومن متصفح محفظة يدعم Ethereum Sepolia نجربو التسجيل والتحقق.

**الحالة:** رفع الملفات لـ GitHub لا يعني أن الموقع منشور أو العقد منشور. كل خطوة تُؤكد برابط أو نتيجة فعلية.

## اختبار آلي
```bash
node --test tests/utils.test.cjs
```
وفي GitHub Actions كنجربو كذلك Solidity compiler. هذا لا يعوّض اختبارات EVM أو تدقيق الأمان.

### حماية المستخدم
- ما ترفَع حتى محتوى حساس أو مفتاح خاص.
- واجهة الموقع تستعمل `eth_sendTransaction` من محفظتك، والتوقيع بيدك فقط.
- عقد المشروع ما فيه لا توكن ولا صلاحيات سحب فلوس ولا رسوم خاصة بالمشروع.
